# NLM

Локальный аналог NotebookLM. Закидываешь свои документы — а потом ищешь по ним по смыслу и общаешься с ассистентом, который отвечает строго по их содержимому и ссылается на источники. Всё работает локально

## Что умеет
- Семантический поиск по документам — не по ключевым словам, а по смыслу, в том числе между разными языками.
- Чат с ассистентом: он опирается на найденные фрагменты, а если чего-то не знает — честно предупреждает.
- Форматы: pdf, docx, pptx, xlsx, html, epub, csv, md, txt.
- Теги для источников и mind-map связей между документами.
- Обычное десктопное приложение, под Windows собирается в один .exe.

## Как устроено
Тексты нарезаются на куски и превращаются в эмбеддинги (Qwen3-Embedding-0.6B), потом они сжимаются с 1024 до 128 измерений почти без потери качества (recall@10 ≈ 0.976). За счёт этого база компактнее, а поиск быстрее. Векторы лежат в Postgres + pgvector (HNSW, косинусное расстояние), сверху — LLM-агент с историей диалога и памятью (по дефолту gpt 5.6).

## Запуск (Linux)
```bash
pip install -r requirements.txt
python app.py
```
Postgres поднимается сам через pgserver — отдельно ставить ничего не нужно. Модель эмбеддера скачается с HuggingFace при первом запуске. При наличии GPU эмбеддер и сжимающая сеть автоматически считаются на нём.

Ключ к LLM задаётся в настройках приложения или в `.env` (`BASE_URL`, `MODEL`).
